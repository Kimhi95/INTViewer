# INTViewer

Windows용 간단한 읽기 전용 `.txt` 뷰어입니다.

## 기능

- 파일 열기 대화상자 및 드래그 앤 드롭
- 첫 화면에서 최근에 열었던 파일 목록 제공
- 최근 파일 선택 또는 새 파일 추가 시 뷰어 화면으로 전환
- 최근 파일 기록 제거 및 전체 삭제
- 뷰 페이지는 텍스트만 표시하고 창 너비에 맞춰 자동 줄바꿈
- 뷰 페이지에서 `Esc` 키로 목록 페이지 복귀
- 우상단 호버 설정 버튼에서 배경색과 글자색 변경
- RGB 색상 슬라이더 조절 즉시 화면에 반영하고 바깥 클릭 시 자동 닫기
- 목록 페이지에서도 환경설정 열기
- 다크 모드에서 Windows 제목 표시줄까지 어둡게 표시
- 다크 모드에서 목록 페이지의 배경·카드·텍스트·버튼 색상도 전환
- 스크롤 보기와 창 크기 기반 페이지 보기 전환
- 페이지 보기에서 창 크기를 조절하는 동안 0.3초 간격으로 페이지 재분할
- 문자 검색 및 줄/페이지 번호 이동
- 뷰 하단의 현재/전체 줄·페이지 표시를 클릭해 원하는 위치로 이동
- 최근 파일마다 마지막 읽기 위치를 백분율로 표시
- 최근 파일을 다시 열면 정확한 문자 위치 자동 복원
- 최근 파일 이름·경로 검색 및 중요 파일 고정
- 원본 파일 변경 감지와 다시 불러오기
- 좁은 창에서 제목·설명·버튼이 겹치지 않는 반응형 목록 레이아웃
- 가늘고 둥근 현대식 스크롤바
- `Ctrl+O`로 파일 열기, 페이지 보기에서 `Home`/`End`로 처음·마지막 페이지 이동
- 빠른 설정 변경은 한 번으로 모아 저장하고, 고유 임시 파일·원자적 교체·잠금 재시도로 동시 저장 충돌 방지
- 여러 INTViewer 창에서 동시에 읽기 위치를 갱신해도 기록을 잃지 않는 프로세스 간 저장 잠금
- 일시적인 파일 점유 자동 재시도와 비정상 설정·기록 값의 안전한 범위 자동 보정
- 파일을 연속으로 열 때 이전 읽기를 취소해 늦게 끝난 파일이 현재 화면을 덮지 않도록 처리
- 다른 파일 열기·인코딩 변경·재불러오기·목록 복귀·종료 직전에 현재 읽기 위치와 책갈피 즉시 보존
- 실제 글꼴의 글리프 폭을 이용한 빠르고 정확한 페이지 분할
- 마지막 페이지에서 다음 페이지 동작을 실행하면 목록 페이지로 복귀
- 창 크기·여백 조절은 지연 재계산하고, 연속 스크롤 갱신은 제한해 조작 중 끊김 완화
- 자동 감지 외 UTF-8·UTF-16·UTF-32·CP949 인코딩으로 다시 열기
- 검색 결과 현재/전체 표시, 대소문자 구분, 단어 단위 검색
- 줄 간격 설정, `F11` 전체 화면, 화면 좌우 클릭 페이지 이동
- 여러 책갈피 저장 (`Ctrl+B`) 및 다음 책갈피 이동 (`F2`)
- 폰트 새로고침과 미리보기
- 마지막 파일 자동 열기 옵션
- Windows TXT 기본 앱 설정 바로가기
- 기록·설정 자동 백업 및 손상 파일 복구
- 페이지 보기에서 단어 경계를 기준으로 줄바꿈
- 뷰 페이지의 목록·검색·환경설정 단축 버튼
- 620px 이하 좁은 창에서 헤더·목록 작업·기록 설정을 세로로 재배치하는 반응형 디자인
- 모바일형(390×720), 4:3(800×600), 16:9(1280×720)의 목록·스크롤 보기·페이지 보기 렌더링 스냅샷 및 화면 경계 자동 검사
- 넓은 화면에서는 본문 폭을 읽기 편한 1080px 이내로 유지하고, 모바일에서는 사용 가능한 폭을 그대로 활용
- 최근 파일을 개별 카드와 읽기 진행률 배지로 구분해 파일명·경로·상태의 시각적 위계 강화
- 본문과 겹치지 않는 전용 하단 영역에 간결한 줄·페이지 이동 컨트롤 표시
- 키보드로 접근한 숨김 읽기 도구는 즉시 표시하고, 환경설정은 다시 열 때 항상 첫 항목부터 표시
- 페이지 계산 결과를 항상 UI 스레드에서 적용해 비표준 실행 환경에서도 WPF 스레드 예외 방지
- 둥근 포커스 입력칸, 자체 콤보박스·체크박스·슬라이더·토글 디자인과 다크 모드 입력 테마
- 최근 파일 필터와 본문 검색 입력 안내 문구
- 목록 검색 결과가 없을 때 전용 안내와 검색어 지우기 버튼 표시
- 목록 페이지에서 `Ctrl+F` 또는 `Ctrl+L`로 최근 파일 검색, `Enter`로 첫 결과 열기
- 최근 파일 검색에서 `↓`로 목록 진입, 목록에서 `Enter`로 파일 열기
- 본문 검색창에서 포커스를 유지한 채 `Enter`/`Shift+Enter`로 다음·이전 결과 연속 탐색
- 반복 문자가 많은 문서는 검색 위치를 최대 100,000개까지만 보관하고 추가 결과는 `+`로 안내
- `Ctrl+G`로 현재 줄·페이지 이동 입력 바로 열기
- 읽기 위치를 문서 처음으로 되돌린 경우에도 위치 0을 정확히 저장
- 아이콘 버튼과 주요 입력 컨트롤에 스크린리더용 접근성 이름 제공
- 환경설정·검색·책갈피 패널을 열고 닫을 때 키보드 포커스를 내부와 읽기 화면 사이에서 자동 복원
- 같은 글꼴의 Regular/Bold 파일은 하나의 글꼴 패밀리 항목으로 통합
- 버튼 포커스 링을 겹침 방식으로 표시해 포커스 전후 크기 고정
- 콤보박스의 본문과 화살표를 포함한 전체 영역 클릭 지원
- 현재 위치의 책갈피 여부를 빈 별/채운 별로 표시하고 책갈피 목록에서 이동·삭제·전체 삭제 지원
- 최근 파일 고정/해제 후에도 선택 항목과 스크롤 위치 유지
- 운영체제 기본 메시지박스 대신 화이트·다크 테마 대응 커스텀 알림 사용
- 삭제 확인 알림은 기본 선택을 ‘아니오’로 두어 실수 방지
- 화이트/다크 모드 버튼에 현재 선택 상태 표시
- RGB 게이지와 함께 클릭·드래그 가능한 색상 팔레트 제공
- 최근 파일 항목 더블클릭으로 바로 열기
- 마지막으로 조절한 창 너비와 높이를 다음 실행 때 복원
- 실행 파일 옆 `font` 폴더의 TTF/OTF 글꼴만 선택 가능
- 선택한 폰트와 굵게·기울임 서식 저장
- 작은 창에서도 환경설정 제목과 닫기 버튼은 고정하고 설정 항목만 스크롤
- 최소 창 너비 480px 지원
- BOM 기반 UTF-8, UTF-16, UTF-32 감지
- BOM 없는 UTF-8 검증 및 UTF-16 추정
- 그 외 한국어 텍스트는 CP949로 처리
- 자동 UTF-8 판별 시 중간 문자열 생성을 생략해 파일 열기 메모리 사용 감소
- 메모리 부족 종료를 막기 위해 최대 128MB 텍스트 파일까지 지원
- 최근 파일 목록에 감지된 인코딩과 읽기 진행률 표시
- 실행 파일에 `.txt` 경로를 전달하여 바로 열기

최근 파일 기록은 `INTViewer.exe`와 같은 폴더의 `history.json`에 저장됩니다. 뷰 설정은 같은 위치의 `settings.json`에 저장됩니다. 기록을 지워도 원본 텍스트 파일은 삭제되지 않습니다. 사용할 글꼴은 EXE 옆 `font` 폴더에 `.ttf` 또는 `.otf` 형식으로 넣고 프로그램을 다시 실행하면 됩니다.

정상 저장 파일이 갱신될 때마다 `history.json.bak`, `settings.json.bak` 백업이 만들어집니다. JSON이 손상되면 백업을 자동 복원하고 손상본은 `.corrupt` 파일로 보존합니다.

> BOM이 없는 레거시 텍스트 파일의 인코딩은 파일 내부에 정보가 없으므로 추정 결과가 항상 정확할 수는 없습니다.

## 개발 빌드

```powershell
dotnet build -c Release
```

## 스모크 테스트

```powershell
dotnet run --project Tests\INTViewer.SmokeTests.csproj -c Release
```

## 단일 EXE 게시

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

완성 파일은 `publish\INTViewer.exe`입니다.
